# project-2_Mikhailov_M26-555

Консольная база данных: управление таблицами и CRUD-операции со строками.
Python 3.12 или новее, менеджер пакетов uv.

## Установка и запуск

Из корня проекта:

```console
uv sync
uv run database
```

Команда `uv run project` запускает ту же программу. Можно также использовать
`uv run python -m primitive_db.main`.

Для установки из собранного пакета в PowerShell:

```powershell
uv build
uv tool install .\dist\primitive_db-0.1.0-py3-none-any.whl
database
```

Если пакет уже установлен, добавьте к `uv tool install` флаг `--reinstall`.
Если команда `database` не найдена, выполните `uv tool update-shell`
и перезапустите терминал.

## Управление таблицами

```text
+------------------------------------+------------------------+
| Команда                            | Действие               |
+------------------------------------+------------------------+
| create_table <имя> [<столбец:тип>] | Создать таблицу        |
+------------------------------------+------------------------+
| list_tables                        | Показать список таблиц |
+------------------------------------+------------------------+
| drop_table <имя>                   | Удалить таблицу        |
+------------------------------------+------------------------+
| help                               | Показать справку       |
+------------------------------------+------------------------+
| exit                               | Завершить программу    |
+------------------------------------+------------------------+
```

В квадратных скобках обозначен список столбцов в формате `имя:тип`.
Несколько столбцов указываются через пробел.

Поддерживаемые типы столбцов: `int`, `str`, `bool`.
Столбец `ID:int` добавляется первым автоматически. Если указать `ID:int`
самостоятельно, он не дублируется. Другой тип для `ID` и повторяющиеся имена
столбцов не допускаются. У таблицы должен быть хотя бы один указанный столбец.
Имена с пробелами заключаются в кавычки.

Пример работы после запуска `database`:

```text
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool
>>>Введите команду: create_table users name:str
Ошибка: Таблица "users" уже существует.
>>>Введите команду: list_tables
- users
>>>Введите команду: drop_table users
Таблица "users" успешно удалена.
>>>Введите команду: drop_table products
Ошибка: Таблица "products" не существует.
>>>Введите команду: exit
```

При неизвестной команде или некорректных аргументах программа выводит сообщение
и снова запрашивает ввод. Пустой ввод пропускается.

## CRUD-операции

```text
+-------------------------------------------------------------+--------------------------------+
| Команда                                                     | Действие                       |
+-------------------------------------------------------------+--------------------------------+
| insert into <таблица> values (<значения>)                   | Добавить запись                |
+-------------------------------------------------------------+--------------------------------+
| select from <таблица>                                       | Показать все записи            |
+-------------------------------------------------------------+--------------------------------+
| select from <таблица> where <столбец> = <значение>          | Выбрать записи по условию      |
+-------------------------------------------------------------+--------------------------------+
| update <таблица> set <столбец> = <значение> where <условие> | Обновить записи                |
+-------------------------------------------------------------+--------------------------------+
| delete from <таблица> where <столбец> = <значение>          | Удалить записи по условию      |
+-------------------------------------------------------------+--------------------------------+
| info <таблица>                                              | Показать схему таблицы и       |
|                                                             | количество записей             |
+-------------------------------------------------------------+--------------------------------+
```

Перед работой со строками создайте таблицу через `create_table`.
В `insert` значения задаются в порядке столбцов схемы, без `ID`.
Все поля обязательны. Новый ID вычисляется как максимальный существующий ID + 1;
для пустой таблицы это 1. Менять `ID` через `update` нельзя.

Строковые значения должны быть в одинарных или двойных кавычках.
Для `int` указывается целое число без кавычек, для `bool` — `true` или `false`.
Например, `28`, `"28"` и `true` имеют разные типы: строка или логическое значение
не подойдут для столбца `int`. Запятые, пробелы и знаки `=` внутри кавычек
сохраняются в строке.

В `set` можно изменить несколько полей через запятую:
`set age = 29, is_active = false`.
В `where` поддерживается равенство; несколько условий объединяются через `and`:
`where age = 29 and is_active = false`.
Команды и ключевые слова можно вводить в любом регистре.

`update` и `delete` требуют `where` и применяются ко всем подходящим записям.
Неизвестные столбцы, неверное количество значений и ошибки типов отклоняются.
Если подходящих записей нет, программа сообщает об этом.
Результат `select` выводится через PrettyTable.

Пример полного цикла:

```text
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool
>>>Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".
>>>Введите команду: select from users where age = 28
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+
>>>Введите команду: update users set age = 29 where name = "Sergei"
Запись с ID=1 в таблице "users" успешно обновлена.
>>>Введите команду: delete from users where ID = 1
Запись с ID=1 успешно удалена из таблицы "users".
>>>Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 0
```

## Хранение метаданных и данных

Все таблицы и описания столбцов сохраняются в `db_meta.json` в текущей рабочей
папке. При каждом проходе цикла программа загружает актуальные метаданные.
После успешного создания или удаления таблицы файл обновляется.
При повторном запуске из той же папки таблицы сохраняются.

Если файла ещё нет, база считается пустой. Повреждённый JSON вызывает сообщение
об ошибке и завершение программы. Такой файл не перезаписывается автоматически.
Строки каждой таблицы хранятся отдельно: например, `data/users.json`.
Файл содержит список словарей с ключами по именам столбцов и типизированными
значениями. `insert`, `update` и `delete` сохраняют результат после успешной
операции. При отсутствии файла данных таблица считается пустой.
JSON записывается сначала во временный файл и затем заменяется целиком.
При удалении таблицы через `drop_table` её файл данных тоже удаляется.

`db_meta.json` и папка `data/` исключены из Git.
Имя таблицы должно подходить для имени файла: пути и служебные имена Windows
не допускаются. В Windows нельзя создать вторую таблицу с именем,
отличающимся от существующего только регистром букв.

Разбор команд, условий `where` и выражений `set` находится в
`src/primitive_db/parser.py`, обработка ввода и вывод — в `engine.py`,
операции над данными — в `core.py`, чтение и запись JSON — в `utils.py`.
