# Primitive DB

Консольная база данных на Python 3.12+: таблицы, CRUD-операции и хранение в JSON.

## Установка и запуск

Нужен [uv](https://docs.astral.sh/uv/). Из корня проекта:

```console
uv sync
uv run database
```

Альтернативы: `make install`, `make run`. Команда `uv run project` также запускает БД.
Проверка стиля: `uv run ruff check .` или `make lint`. Сборка: `uv build`.

## Команды

| Команда                                                   | Действие                       |
| --------------------------------------------------------- | ------------------------------ |
| `create_table <имя> [<столбец:тип>]`                      | Создать таблицу                |
| `list_tables`                                             | Показать таблицы               |
| `drop_table <имя>`                                        | Удалить таблицу                |
| `insert into <имя> values (<значения>)`                   | Добавить запись                |
| `select from <имя>`                                       | Показать все записи            |
| `select from <имя> where <столбец> = <значение>`          | Найти записи                   |
| `update <имя> set <столбец> = <значение> where <условие>` | Обновить записи                |
| `delete from <имя> where <столбец> = <значение>`          | Удалить записи                 |
| `info <имя>`                                              | Показать схему и число записей |
| `help` / `exit`                                           | Справка / выход                |

В `create_table` укажите один или несколько столбцов через пробел; типы: `int`, `str`, `bool`.
`ID:int` создаётся автоматически. В `insert` передавайте все остальные значения по порядку,
через запятую: строки в кавычках, целые числа без кавычек, логические — `true` / `false`.
В `set` несколько полей разделяются запятыми, в `where` условия равенства — словом `and`.

Удаление требует ответа `y`; другой ответ отменяет действие. При ошибках в командах
программа выводит сообщение и продолжает работу. Для `insert` и `select` выводится
время выполнения, повторные выборки кэшируются. Схемы хранятся в `db_meta.json`,
строки — в `data/<имя>.json`.
